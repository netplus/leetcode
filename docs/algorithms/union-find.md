# 并查集：只维护“是否属于同一连通集合”

## 1. 一般问题

如果图不断加入等价关系或无向边，而查询只关心 `x` 和 `y` 是否已经属于同一组，每次重新 DFS/BFS 会反复搜索整个连通块。

## 2. 只保留代表元

每个集合选一个 root：

```text
find(x) = x 所在集合代表
```

判断连通只需比较 `find(x)==find(y)`；合并则把两个代表元连接起来。

## 3. 路径压缩

`find` 过程中把沿途节点直接挂到根：

```text
x -> ... -> root
变成
x ------> root
```

后续查询越来越快。

## 4. 按秩 / 按大小合并

总把小树挂到大树，避免树高不断增长。路径压缩 + 按秩合并后，均摊复杂度接近 O(1)。

## 5. 环检测

无向图逐边加入时，若加入 `(u,v)` 前 `find(u)==find(v)`，说明已经存在一条 u 到 v 的路径，新边会形成环。

## 6. 等价约束

`a==b` 具有传递性，可先全部 union；然后检查 `a!=b` 是否落入同一个等价类。

## 7. 有向图注意

并查集天然表示无向连通关系。像 LC-685 还需要额外处理入度 2 等有向结构约束，不能只套无向环检测。
