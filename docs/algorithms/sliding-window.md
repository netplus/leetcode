# 滑动窗口：复用相邻区间状态，让左右边界只向前走

## 1. 一般问题

很多连续子数组 / 子串题的暴力写法是：固定 left，向右寻找一个满足条件的 right；换下一个 left 后又重新统计。相邻候选高度重叠，却常从零计算。

## 2. 核心规律

窗口从 `[L,R]` 变到相邻状态时，变化通常只有：

```text
右边进入一个元素
左边离开一个元素
```

如果窗口状态能增量更新，就不必重新扫描内部。

## 3. 可变长度窗口

常见结构：

```cpp
for (right ...) {
    add(right);
    while (window 需要收缩) {
        remove(left);
        ++left;
    }
    update_answer();
}
```

关键不是背 while，而是证明 `left` 为什么永远不用回退。通常需要正数、频次覆盖、无重复等单调条件。

## 4. 固定长度窗口

长度固定为 k 时，每右移一格只发生两个事件：加入一个、移出一个，因此状态更新天然 O(1)。

## 5. 窗口状态

可维护当前和、字符频次、missing/satisfied 摘要、最近冲突位置，或与单调队列组合维护最大值。

不要每次重新扫描整张频次表，如果能用一个摘要变量表示“还有多少条件未满足”。

## 6. 何时不能用

若数组含负数，`right` 右移可能让和变小，`left` 右移也可能让和变大，会破坏“边界单向修复”的单调性。因此“连续区间”并不自动等于滑动窗口。

## 7. 典型题

- LC-209：正数和阈值
- LC-3：无重复窗口
- LC-76：覆盖需求
- LC-438：固定长度频次窗口
- LC-239：窗口 + 单调队列
