# 二分搜索：在单调候选空间中一次排除一半

## 1. 核心不是 mid

二分真正依赖的是：一次判断可以证明一整段连续候选都不可能是答案。`mid` 只是选择一个测试点。

## 2. 查具体值

有序数组中：

```text
a[mid] < target
=> [left,mid] 都太小
=> left = mid+1
```

这是最直接的值域单调性。

## 3. 查边界

更通用的形式是：找第一个满足单调谓词 `P(x)` 的位置。例如第一个 `>= target`、最小可行速度、最小可行容量。

## 4. 答案二分

原题可能不是“在数组里查值”，而是求一个最优整数答案。如果给定 candidate 能快速判断是否可行，并且可行性随 candidate 单调变化，就可在答案范围二分。

```text
答案下界 / 上界
    ↓
check(mid)
    ↓
根据可行性缩小区间
```

## 5. 如何确定上下界

必须来自题意。例如船容量下界是最大单件重量，上界是总重量；吃香蕉速度下界是 1，上界是最大堆大小。边界不是模板常数。

## 6. 旋转数组

整体不单调也可能二分，只要每次能识别一半具有足够结构，从而安全排除另一半。

## 7. 防止死循环

必须统一区间语义，例如 `[left,right]` 或 `[left,right)`，并让每个分支都严格缩小搜索区间。
