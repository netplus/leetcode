# 双指针：让边界单调移动，一次排除一批候选

## 1. 一般问题

双指针不是“两根变量”的模板。它适合这样的问题：候选由两个位置或两个边界共同决定，而一次比较能够证明某个边界相关的一整批候选不可能更优，因此该边界可以永久移动、不再回退。

## 2. 最自然的一般实现

最直观往往是枚举所有 `(left,right)`：

```text
for left:
    for right:
        evaluate(left,right)
```

问题在于一次只排除一个组合，没有利用排序、单调性或支配关系。

## 3. 相向双指针

若数组有序：

```text
left ->          <- right
```

当前和过小，移动 left；当前和过大，移动 right。

正确性来自批量淘汰：当前最小 left 与当前最大 right 都还太小时，保留这个 left 再换更小 right 更不可能成功，所以 left 可以永久淘汰。

## 4. 快慢指针

另一类双指针是两个职责：

```text
read  : 发现 / 检查元素
write : 下一个应写入 / 保留的位置
```

典型如移动零、稳定过滤。

## 5. 固定间距

链表倒数第 k 个问题中，fast 先领先固定距离，随后 fast/slow 同速；当 fast 到终点时，slow 的相对位置由间距自动确定。

## 6. 两端边界结算

接雨水一类题中，某一侧的限制条件一旦已经由当前已知最大值确定，该侧位置答案就可以结算并向内移动。

## 7. 识别条件

使用双指针前应回答：

1. 两个边界是否都只需单向移动？
2. 当前判断为什么能让某个边界永不回头？
3. 被跳过的整批候选为什么永远不可能成为答案？

答不清第 3 个问题，就还不能安全使用双指针。
