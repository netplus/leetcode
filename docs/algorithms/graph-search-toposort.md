# 图搜索、BFS/DFS 与拓扑排序：从 frontier 和依赖关系出发

## 1. 连通分量

若题目问有多少块、每块多大：全局扫描发现一个未访问起点，一次 DFS/BFS 吃掉整个连通分量，再继续全局扫描。visited 表示“该状态已经归属某个已处理分量”。

## 2. BFS 为什么得到最短无权距离

队列按层扩展：`distance d` 的所有节点先于 `distance d+1` 被处理。一个节点第一次被到达时就是最短距离，因此通常应在入队时标记 visited，避免同层重复入队。

## 3. 多源 BFS

若有多个等价起点，把所有源一起放入第 0 层，而不是分别 BFS。典型如腐烂橘子、01 矩阵。

## 4. 隐式图

有些题没有显式邻接表，但可根据规则即时生成邻居，例如单词改一个字符、网格四邻、状态变换。不必先把完整图构造出来。

## 5. 反向搜索

若问“哪些点能到达某组终点”，可以把边方向反过来，从所有终点统一向外搜，把很多起点重复搜索变成一次多源搜索。

## 6. 拓扑排序

有向依赖图中：

```text
入度 0 = 当前没有未完成前置依赖
```

反复处理入度 0 节点并删除其出边。若最终处理节点数少于 n，剩余节点互相依赖，说明存在环。

## 7. DFS 还是 BFS

- 只需连通性：二者都可；
- 无权最短距离 / 时间层：BFS；
- 递归结构、路径枚举：DFS 更自然；
- 依赖顺序：拓扑 BFS 或 DFS 均可，但要明确环检测语义。
