# 区间排序与扫描线：先制造顺序，再维护当前活动状态

## 1. 一般问题

区间之间的关系本来是二维的：任意两段都可能相交，直接两两比较常是 O(n^2)。如果先按某个端点排序，很多全局关系会变成局部连续关系。

## 2. 合并区间

按 start 排序后，只需维护当前已经合并出的区间 `[L,R]`。下一段 `[l,r]` 若 `l<=R` 就继续扩张 `R=max(R,r)`；否则当前段封口，开启新段。

注意比较的是“已经扩张后的当前并集”，不是原数组前一个区间。

## 3. 会议冲突

按 start 排序后，如果当前会议与前一场不冲突，它也不会与更早结束的会议冲突，因此任意两两冲突检查可以压缩成相邻扫描。

## 4. 扫描线

更一般地，可以把区间转成边界事件：

```text
start : 活动状态加入
end   : 活动状态移除
```

按位置或时间排序事件，再维护当前 active 集合或计数。

## 5. 端点语义

闭区间 `[L,R]` 与半开区间 `[L,R)` 会改变 `end == next.start` 是否算重叠。必须先定义题目语义，再决定使用 `<` 还是 `<=`。

## 6. 堆配合扫描

会议室 II 中按开始时间扫描，最小堆保存正在占用房间的结束时间；只需检查最早结束的房间是否能复用。

## 7. 典型题

- LC-56 / 57：区间合并
- LC-252：冲突判定
- LC-253：房间数 / 活动集合
