# 前缀和与差分：复用累计状态、记录边界变化

## 1. 一般问题

这类题通常反复做两件事之一：

```text
A. 多次查询某段区间的累计结果
B. 多次给整段区间施加相同变化
```

如果每次都逐点扫描或写入，就会重复处理大量重叠区域。

## 2. 前缀和从哪里来

对不可变数组，多次查询 `[L,R]` 时，直接求和会反复累加相同前缀。把从起点到每个边界的累计值保存：

```text
prefix[i] = 前 i 个元素的和
```

则：

```text
sum[L..R] = prefix[R+1] - prefix[L]
```

本质是两份累计状态相减，公共前缀自动抵消。

## 3. 前缀频次

固定右端点后：

```text
currentPrefix - oldPrefix = target
oldPrefix = currentPrefix - target
```

于是“枚举所有区间”可以转成“查询某个历史前缀值出现过多少次”。

## 4. 二维前缀

二维矩形遵循同一思想，只是公共区域需要容斥：目标矩形 = 大左上矩形 - 上方 - 左方 + 被减两次的左上角。

先画矩形，再写四项公式，通常比直接背公式更稳。

## 5. 差分从哪里来

区间加法：

```text
[L,R] 每个位置都 += x
```

区间内部没有新事件，`+x` 只是持续有效，因此只记录：

```text
L      : +x 开始生效
R + 1  : -x 取消这份状态
```

再用：

```text
running += diff[i]
```

一路恢复当前位置真实状态。

## 6. 统一视角

```text
前缀和：局部数据 -> 累计边界状态 -> 快速查询
差分：边界变化事件 -> 累计恢复 -> 局部真实状态
```

二者互为一类“累计 / 变化”转换。

## 7. 边界

`prefix[0]=0` 与额外 `diff[n]` 都不是魔法：空前缀让从 index 0 开始的区间也能复用主公式；`diff[n]` 表示最后真实位置之后的虚拟取消点。

## 8. 典型题

- LC-303 / 304：区间查询
- LC-560 / 1248：前缀频次
- LC-1109：差分区间更新
- LC-238：前缀 / 后缀累计
