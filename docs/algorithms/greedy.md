# 贪心：证明“当前可以安全永久淘汰什么”

## 1. 贪心不是“看起来最划算”

贪心算法的关键不是局部选择本身，而是证明：做出当前选择后，不会失去任何全局最优解。

常见证明方式包括支配关系、交换论证、最远边界、排序后最小资源匹配，以及一次失败淘汰整段候选。

## 2. 支配

跳跃游戏中，同一前缀下，能到更远的位置完全支配只能到更近的位置，因此只保留一个最远可达边界。

## 3. 交换论证

如果某个解中相邻 A、B 顺序不合理，而交换成 B、A 不会更差甚至更好，就可以证明存在一个最优解满足该局部排序规则。典型如最大数的自定义排序。

## 4. 最小资源满足最小需求

分发饼干中，用“刚好能满足当前最小胃口的最小饼干”，留下更大资源给未来约束更强的孩子。

## 5. 区间覆盖

Jump Game II 不是每个点立即跳，而是扫描“当前一步覆盖区间”，同时收集下一步最远边界；到达当前边界时才统一进入下一跳。

## 6. 识别问题

使用贪心前必须能回答：

```text
被我丢弃的其它候选为什么以后永远不可能反超？
```

若只能回答“经验上这样最好”，证明还不够。
