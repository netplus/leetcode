# 回溯：在搜索树中维护“当前路径 + 可选集合”

## 1. 一般问题

排列、组合、子集、棋盘路径等问题都可以看成：当前已经做了一部分选择，下一步有哪些合法选择，然后选择一个继续。

如果需要枚举所有合法方案，搜索树通常无法完全避免；关键在于避免重复分支和尽早剪掉非法前缀。

## 2. 三段式

```text
做选择 -> 递归 -> 撤销选择
```

撤销不是模板仪式，而是为了让同层下一个候选看到与进入本层前相同的状态。

## 3. start 的意义

组合 / 子集不关心顺序。若每层都从 0 枚举，`[2,3]` 和 `[3,2]` 会被当成两条路径。规定下标只向右选，为每个集合建立唯一构造顺序。

## 4. used 的意义

排列要求每个位置都可从所有“尚未使用”的元素中选择，因此需要 used 区分当前路径已经占用哪些元素。

## 5. 剪枝

正确剪枝必须证明：当前前缀一旦违反某条件，所有继续扩展都不可能恢复合法。例如括号生成中 `close > open` 的前缀永远不可能变成合法括号串。

## 6. 网格回溯

visited 往往是“当前路径状态”，不是全局永久状态：进入格子时标记，递归邻居，离开路径时恢复。这与图连通分量的永久 visited 完全不同。
