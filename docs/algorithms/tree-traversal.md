# 树遍历与树形状态：先定义“子树返回什么”

## 1. 树题的第一问题

不要先问 DFS 还是 BFS，先问：

```text
站在一个节点上
我需要从孩子得到什么信息？
当前节点要做什么？
我要向父亲返回什么？
```

递归函数语义比遍历名称更重要。

## 2. 前 / 中 / 后序

三种顺序的差别是“什么时候处理当前节点”：

```text
前序：根 -> 左 -> 右
中序：左 -> 根 -> 右
后序：左 -> 右 -> 根
```

如果父节点的答案依赖两个孩子结果，后序最自然。

## 3. 显式栈 = 手动保存递归现场

迭代 DFS 不是另一套算法：递归调用栈保存的暂停现场，可以改由自己用 stack 显式保存。因此要理解节点为什么入栈、何时可访问，而不是只记压栈顺序。

## 4. BFS = 层 frontier

队列保存当前尚未扩展的节点。若需要层信息，先读取 `levelSize = queue.size()`，把当前已有节点当成这一层，新加入节点留给下一层。

## 5. 树形 DP 的两个常见口径

例如最大路径和：用于全局答案的路径可以在当前节点分叉；返回父节点的状态只能选择一条向下路径。不要把“当前子树完整答案”和“能继续向父节点延伸的状态”混为一个变量。

## 6. 祖先约束

BST 验证一类题不是局部父子关系，而是深层节点必须继承所有祖先约束。可以传上下界，或利用中序遍历具有全局严格递增性质。
