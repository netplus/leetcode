# 单调队列：在移动窗口中只保留仍可能成为最优值的候选

## 1. 一般问题

滑动窗口最大值最自然是每个窗口重新扫描 k 个元素，O(nk)。相邻窗口高度重叠，真正需要解决的是：哪些旧元素以后还有机会成为最大值？

## 2. 支配关系

若新元素 `new >= old`，而且 new 下标更晚：只要 old 还在窗口，new 也一定还在窗口，并且 new 不小于 old。因此 old 永远不可能再成为最大值，可以永久删除。

## 3. 为什么是 deque

需要同时做两种删除：

```text
队尾：删除被新元素支配的候选
队首：删除已经离开窗口的过期候选
```

因此需要双端队列。

## 4. 不变量

队列通常存下标：下标从前到后递增，对应值从前到后单调递减，于是 `q.front()` 始终是当前窗口最大值位置。

## 5. 摊还复杂度

每个下标入队一次，最多从队首或队尾出队一次，因此总操作 O(n)。

## 6. 典型题

- LC-239：窗口最大值
- 进一步可用于窗口最小值、带约束前缀优化等问题
