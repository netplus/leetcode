# 栈与队列：未完成上下文与 frontier

## 1. 栈解决什么

栈的核心是 LIFO：最近进入、最先退出。它适合保存“最近开启但还没完成”的上下文，例如括号嵌套、递归调用现场、表达式求值和单调栈中的未决历史状态。

### 括号为什么用栈

合法嵌套要求后开启的结构必须先关闭，因此右括号只需检查最近一个未闭合左括号。

## 2. 队列解决什么

队列 FIFO：先进入、先处理。它适合维护 BFS frontier：当前待扩展节点被处理时，把更远一层节点加入队尾，于是状态按距离 / 时间层次自然推进。

## 3. 栈上的摘要状态

Min Stack 说明一个重要扩展：每层不仅保存 value，还保存进入这一层后的 summary。pop 后旧 summary 自动恢复，无需重新扫描历史。

这种思路可以推广到 minimum、maximum、gcd 等可回滚统计量。
