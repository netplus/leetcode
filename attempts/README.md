# 独立作答

本目录保存学习者自己的思路和实现，不是参考题解目录，不由 `tools/gen_all.py` 管理。

## 保存规则

建议目录为 `attempts/<日期>-<题目标识>/`，其中可包含：

```text
approach.md       # 首次思路、是否已见、提示等级、用时
v1.cpp            # 原始实现，不在复盘后覆盖
v2.cpp            # 修订实现，仅在确有第二版时保存
tests.md          # 实际测试输入、预期输出、实际结果与执行方式
```

只保存真实产生的文件，不预先生成空实现或模型代写的“独立作答”。学习者口述由助手整理时，应注明“根据口述整理”；助手编写的示范代码应明确标注，不计为学习者独立实现。

## 最小思路记录

```markdown
# <题目标识> 首次作答

日期：
是否见过该题或等价题：
训练形式：专题 / 无标签混合 / 模考 / 延迟复测
提示等级：H0 / H1 / H2 / H3
用时与来源：未计时 / 学习者计时 / 执行日志

## 原始思路
保留首次表达，必要的整理不改变其含义。

## 尚未确定之处

## 验证
注明口述审阅、静态审阅或实际执行，不将它们混为一谈。
```

个人作答不要直接覆盖 `problems/**/solution.cpp`。后者是由 canonical 数据生成的参考材料，重新生成可能覆盖修改。

对应掌握度与提示定义见 [PROGRESS.md](../PROGRESS.md#题型掌握度记录)，训练顺序见 [TRAINING.md](../TRAINING.md)。
