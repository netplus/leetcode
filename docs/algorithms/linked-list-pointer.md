# 链表指针技巧：把“位置问题”转成局部指针关系

## 1. 链表与数组最大的不同

单链表只有 `node -> next`，没有 O(1) 随机下标，也不能直接从尾部向前。因此链表题的核心往往不是复杂算法，而是：如何在不丢链的前提下重连局部指针，以及如何用相对位置替代绝对下标。

## 2. 原地反转的基本图

```text
已反转前缀 <- current -> 未处理后缀
        prev      next
```

修改 `current->next` 前必须先保存 next。

不变量：`prev` 是已完成部分的头，`current` 是下一待处理节点。

## 3. dummy 节点

当头节点可能被删除、插入或反转时，加一个虚拟前驱：

```text
dummy -> head -> ...
```

让“修改原头”与“修改中间节点”使用同一逻辑。

## 4. 快慢指针

典型用途包括中点、倒数第 k 个、环检测、环入口和两链表路径对齐。使用前要先说明两指针之间维持的是速度差、固定距离还是总路径等长。

## 5. 分解式链表题

很多高级题可以拆成基础动作：

```text
找中点 -> 反转一段 -> 合并 / 比较
```

例如回文链表、重排链表。

## 6. 归并

链表特别适合归并排序，因为切段只断 `next`，合并只改 `next`，无需数组式搬移元素。
