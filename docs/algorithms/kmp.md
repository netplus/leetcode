# KMP：失配时复用已经匹配成功的前后缀

## 1. 一般字符串匹配

朴素匹配会从每个文本起点尝试 needle；一旦失配，文本起点右移一格，needle 又从 0 开始。最坏会反复比较相同字符。

## 2. 可以复用什么

假设已经匹配了 `needle[0..j-1]`，然后在 j 失配。若已匹配部分的某个后缀同时也是 needle 的前缀，这部分字符已经由刚才的比较证明相等，不必让文本指针回退。

## 3. LPS

`lps[i]` 表示 `pattern[0..i]` 中最长的“真前缀 == 后缀”长度。

失配时：

```text
j = lps[j-1]
```

表示保留仍然可信的匹配长度。

## 4. 两层复用

KMP 有两个阶段：先预处理 pattern，计算每个状态失配后能退到哪里；再扫描 text，文本指针始终前进，模式指针按 lps 回退。

## 5. 为什么 O(n+m)

文本指针不回退；模式指针虽然可能多次回退，但每次都减少已匹配长度，总推进/回退次数线性受限。

## 6. 学习重点

不要先背 next/lps 数组代码。先理解：

```text
失配后，哪些已经比较成功的字符仍然可以被证明有用？
```
