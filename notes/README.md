# 最小错题复盘

复盘不是抄一遍完整题解，而是保存“这次为什么卡住，以及怎样避免再次卡住”的证据。

建议一题一个 Markdown 文件，并关联 [attempts/](../attempts/README.md) 中的首次作答。没有实际作答，不补造错题记录。

```markdown
# <题目标识> 复盘

原始作答：
题目是否已见：
最高提示等级：

## 卡住的具体位置
题意 / 建模 / 状态 / 决策或转移 / 边界 / 实现 / 复杂度 / 时间分配。

## 暴露问题的最小例子
写出输入、预期结果、原方案的实际结果或推演结果。
区分实际执行与手工推演。

## 原因与修正
原来的理解错在哪里？修改哪条逻辑，为什么？

## 适用边界
哪些条件变化后，当前方法不能直接复用？

## 复测
计划日期与实际日期分开。记录题目标识、是否给提示、结果和证据。
```

未执行的复测保持“待复测”，不自动晋级掌握状态。学习计划中的延迟复测是训练安排，不表示已经创建提醒或后台任务。

掌握度更新入口：[PROGRESS.md](../PROGRESS.md#题型掌握度记录)。
